# Месяц — трекер привычек и воспоминаний

Прототип настольного приложения для Windows. Интерфейс написан на HTML/CSS/JavaScript без сторонних библиотек.

## Что уже работает

- Переключение месяцев и таблица: дни по строкам, привычки по столбцам.
- Циклическое изменение статуса ячейки: не отмечено → выполнено → пропущено.
- Добавление и удаление привычек в плане месяца.
- Раздел воспоминаний по дням и за месяц, выбор фотографий и видео, заметка.
- Локальное сохранение плана и отметок в браузерном хранилище.

## Текущий статус

Это UI-прототип, который можно открыть двойным щелчком по `index.html`. Для настоящего приложения необходимо добавить Electron и безопасный preload-мост. Сейчас выбранный путь к папке запоминается, но браузер не записывает туда медиа; предпросмотр выбранных медиафайлов живёт только в открытой вкладке. Нельзя считать такое хранение архивом.

Папка на Яндекс Диске должна быть обычной локальной синхронизируемой папкой, выбранной пользователем в приложении Яндекс Диск. Приложению не требуются API Яндекса или пароль от аккаунта.

## Следующий этап

1. Установить Node.js вместе с npm на машине разработки.
2. Добавить Electron, `contextIsolation` и IPC-обработчики для выбора папки, записи и чтения медиа.
3. Сохранять привычки и отметки в локальной базе SQLite либо JSON-файле в `%APPDATA%`.
4. Проверить запись файлов в выбранную папку и обработать отсутствие папки/недоступные файлы.
5. Собрать Windows-приложение.

## Запуск прототипа

Откройте `index.html` в современном браузере. Google Fonts используется для оформления и требует интернет; при отсутствии сети применятся системные шрифты.
